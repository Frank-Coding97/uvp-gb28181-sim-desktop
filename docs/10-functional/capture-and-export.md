# 功能规格:本地抓拍图库与日志导出

**状态:已交付(M7)** · 覆盖 FR-47(抓拍)、FR-44(日志导出)· 实现见 `apps/desktop`(Preview.vue / Snapshots.vue / System.vue)+ `crates/media-rtp/src/snapshot.rs` + `crates/common/src/log_redact.rs`。

---

## 1. 目标

联调现场有两类高频诉求:**留证据**(截图给平台方看"设备确实推了这帧")和**带走日志**(把 SIP 报文发给同事排查)。这两件事都必须在断网、无第三方工具的前提下完成,且导出的东西不能反手泄露平台口令。

## 2. 本地抓拍

### 2.1 帧来源

抓拍取的是**预览总线(`DesktopPreviewBus`)上的最新一帧 MJPEG**,与「推流预览」页正在显示的帧同源。

- 不额外打开一次摄像头/屏幕采集:采集侧只有一条 H.264 流,预览是它的旁路。
- 不打断推流:取帧是只读借用,不 reset 总线、不影响平台点播。
- 未出帧时命令直接报错「预览尚未出帧,请先订阅预览或确认设备已推流」。**不落黑图** —— 一张全黑的"证据"比没有更糟。

### 2.2 落盘与命名

- 目录:`<数据根>/snapshots`,与配置、录像同根(`app_data_root`,含 `UVP_CONFIG_DIR` 覆盖与可写探测回落)。
- 文件名:`snap-YYYYMMDD-hhmmss-<captured_at_ms>.jpg`。时间戳用**帧被切出的时刻**,不是落盘时刻;文件名尾部的毫秒值同时用于排序。
- 同一毫秒重复抓拍自动追加 `-1`、`-2` 序号,不覆盖已有文件。

### 2.3 页面

| 位置 | 元素 |
|---|---|
| 推流预览页 | 「抓拍」按钮(未出帧时禁用),成功后 toast 显示尺寸与文件名;「查看抓拍图库 →」入口 |
| 抓拍图库页(`/snapshots`) | 缩略图网格(时间/尺寸/大小)、点击放大、另存为、删除(二次确认)、刷新、加载更多(每页 24,上限 200)、总张数与总占用 |

- 缩略图由 `read_snapshot` 返回 data URL,前端 4 路并发拉取并缓存;一次性铺满几百张会把 base64 全塞进内存。
- 另存为走系统保存对话框,后端原文件复制,不重新编码(避免二次有损)。

## 3. 日志导出

### 3.1 导出范围

导出**当前页签、当前筛选条件下可见的内容**,而不是全量缓冲:导出的东西必须和用户看到的一致,否则"我导出的日志里有几万行没看过的东西"会成为新的争议点。

| 页签 | 内容 |
|---|---|
| SIP 日志 | 结构化追踪(时间/方向/方法/对端/CSeq + 原始报文),含进入本页前的历史 SIP 报文 |
| 系统日志 | 时间/级别/target/消息 |
| 平台命令 | 时间/命令类型/摘要 |

### 3.2 脱敏

脱敏在 Rust 侧 `common::log_redact` 完成,前端只递交原始文本块 —— 前端没有机会漏掉某条路径。

| 抹掉 | 形态 |
|---|---|
| `Authorization` / `Proxy-Authorization` | 整行值替换为 `******`,保留头名 |
| `<Password>` | XML 标签内文本替换 |
| `password=` | 查询串/键值日志的值替换到分隔符为止 |
| `"password"` | JSON 值替换 |

**不脱敏**:`DeviceID`、`Call-ID`、`CSeq`、平台域名、`passwordPolicy` 这类"键名里含 password"的非敏感配置 —— 抹掉它们等于制造新的谜题。

导出文件头固定写入三行注释:导出时间、范围、脱敏说明(含"不可恢复"),避免接收方误以为拿到完整报文。

### 3.3 反馈

导出成功后 toast 报告:`已导出 N 条,脱敏 M 处 → <路径>`。`M=0` 说明这份日志里本来没有凭据,不是漏脱敏。

## 4. 验收

- 预览播放中点击「抓拍」→ 图库出现一张与画面一致的图,尺寸与预览一致;预览未启动时按钮禁用。
- 连续快速点击两次抓拍 → 生成两个文件,不互相覆盖。
- 导出 SIP 页签 → 打开文件,`Authorization` 行只剩头名,`DeviceID`/`Call-ID` 原样保留,文件头有脱敏说明。
- 抓拍目录中放入一个非本程序命名的 `.jpg` → 列表忽略它,不报错。
- 通过 IPC 传 `id: "../config.json"` → 返回「非法抓拍 ID」,不读取目录外文件。
