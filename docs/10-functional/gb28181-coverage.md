## 关键 ID 编码

GB28181 设备/通道 ID 为 20 位:`中心编码(8) + 行业(2) + 类型(3) + 序号(7)`。批量生成虚拟设备按序号递增。详见 `40-protocol/manscdp.md#id-编码` 与 `30-crates/gb28181-protocol.md`。
