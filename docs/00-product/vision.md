# 产品愿景

**状态:已评审**

## 一句话定位

一款多系统桌面应用,把普通电脑变成 GB/T 28181-2022 国标下级设备(IPC),用于**联调**上级平台,更用于对上级平台做**大规模压力测试**。

## 目标用户

| 用户 | 场景 | 痛点 |
|---|---|---|
| 国标平台开发者 | 开发 WVP/UVP 等上级平台时需要下级设备联调 | 没摄像头没法调;买设备贵、配网烦 |
| 平台测试 / QA | 验证平台在海量设备接入下的承载与稳定性 | 缺少能模拟成千上万台设备的工具 |
| 集成 / 运维 | 交付前评估平台容量、排查兼容性 | 现有模拟器闭源、单设备、无压测 |

## 差异化

现有 GB28181 模拟器大多:闭源、只模拟单台或少量设备、无压测能力、协议日志弱。本项目的差异点:

1. **压力测试是一等公民** —— 单机模拟数千至上万台虚拟设备并发注册/心跳/推流,量化平台承载。
2. **多系统桌面端** —— Windows/macOS/Linux 下载即用,无需 JVM/Python/Docker。
3. **引擎与 UI 解耦** —— 核心用 Rust,可脱离 UI 以 CLI 运行,未来支持多机分布式压测。
4. **可视化联调** —— SIP 信令、RTP 推流、成功率曲线、失败归因一目了然。

## 产品原则(优先级从高到低)

1. **易用** —— 非协议专家也能跑通一次压测。
2. **安装简单** —— 单安装包,零外部运行时依赖。
3. **稳定** —— 长时间高并发不崩、资源可控。
4. **高效** —— 单机尽可能高的设备并发规模。
5. **可扩展** —— 为 CLI、分布式压测预留架构。

## 明确不做(当前阶段)

- 不做上级平台(SU 端)本身,只做下级设备(IPC 端)。
- 不做双向语音对讲、GB35114 国密(排期评估)。
- 不做真实摄像头采集(桌面视频源用测试图案/文件循环替代)。
