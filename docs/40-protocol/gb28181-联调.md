# 联调指南:WVP-Pro 上级平台

**状态:草案** · 用开源 WVP-Pro 作上级平台联调单设备/压测。

## 起一个 WVP-Pro

```bash
docker run -d --name wvp \
  -p 18080:18080 -p 5060:5060/udp -p 30000-30500:30000-30500 \
  648540858/wvp_pro:latest
# 控制台 http://localhost:18080  (admin / admin)
```

## 单设备联调参数

在本应用"平台配置 / 设备模板"填:

| 项 | 值(示例) |
|---|---|
| 平台 ID(domain) | `34020000002000000001` |
| 服务地址 | `WVP主机IP:5060` |
| 设备 ID | `34020000001320000001` |
| 认证用户名 | 同设备 ID |
| 密码 | 与 WVP「国标设备」配置一致 |
| 传输 | UDP |

注册成功后 WVP 控制台该设备显示**在线**;点播可见测试码流。

## 压测联调注意

- 压测前在 WVP 侧确认接入域、是否开启鉴权。
- 大规模压测占用大量端口/带宽,**仅在受控内网**进行(NFR-9)。
- WVP 默认 RTP 端口段 30000-30500,压测真推流路数受此限制,可按需调整平台配置。
