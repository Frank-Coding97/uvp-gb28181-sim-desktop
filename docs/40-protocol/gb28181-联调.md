# 联调指南:WVP-Pro 上级平台

**状态:已验证** · 用开源 WVP-Pro 作上级平台联调单设备/压测。以下为实测通过的完整流程。

## 起一个 WVP-Pro

```bash
docker run -d --name wvp \
  -p 18080:18080 -p 5060:5060/udp -p 30000-30500:30000-30500 \
  648540858/wvp_pro:latest
```

## 获取 SIP 参数(通过 WVP API)

WVP 网页登录(admin/admin)只是控制台;设备注册要用 **SIP 配置**。通过 API 查:

```bash
# 登录拿 token(密码取 md5)
PWD=$(printf 'admin' | md5sum | cut -d' ' -f1)   # macOS: printf 'admin'|md5
TOKEN=$(curl -s "http://<WVP>:8080/api/user/login?username=admin&password=$PWD" \
  | python3 -c "import sys,json;print(json.load(sys.stdin)['data']['accessToken'])")
# 查 SIP 配置(域/端口/全局密码)
curl -s -H "access-token: $TOKEN" "http://<WVP>:8080/api/server/system/configInfo"
```

关键字段:`sip.domain`(SIP 域)、`sip.port`(SIP 端口,注意**不是** 5060)、
`sip.password`(全局 SIP 密码,设备密码为空时用它)、`sip.deviceIdStrict`
(true 时只接受已在后台登记的设备 ID)。

## 单设备联调参数(实测示例)

| 项 | 值 |
|---|---|
| 平台域(SERVER_DOMAIN) | `3502000000` |
| 服务地址 | `<WVP>:8160`(SIP 端口,非 Web 端口) |
| 设备 ID | 后台已登记的设备,如 `35020000001310000001` |
| 密码 | `wvp_sip_password`(全局 SIP 密码) |
| 传输 | WVP 点播默认下发 `TCP/RTP/AVP`(设备自动切 TCP 推流) |

命令行联调:

```bash
# 注册 + 心跳
SERVER_HOST=<WVP> SERVER_PORT=8160 SERVER_DOMAIN=3502000000 \
DEVICE_ID=35020000001310000001 PASSWORD=wvp_sip_password \
cargo run -p gb28181-simulator --example register_one

# 带真实码流(可被点播出画面):先 assets/media/gen-test-h264.sh 生成
VIDEO_SOURCE=assets/media/test.h264 ... (其余同上)

# 上报报警:加 ALARM_AFTER_SECS=3
```

验证:
- 注册 → WVP「国标设备」显示**在线**(日志出现"注册成功")
- 目录同步(`/api/device/query/devices/<id>/sync`)→ 通道列表出现设备通道
- 点播(`/api/play/start/<devId>/<chId>`)→ 返回 code:0 + FLV 播放地址(实测出画面)
- 录像查询(`/api/gb_record/query/...`)→ 返回录像段
- 报警 → 平台接受(code 200)

## 压测联调注意

- 压测前在 WVP 侧确认接入域、是否开启鉴权。
- 大规模压测占用大量端口/带宽,**仅在受控内网**进行(NFR-9)。
- WVP 默认 RTP 端口段 30000-30500,压测真推流路数受此限制,可按需调整平台配置。
