## 运行方式

### 开发模式 (daemon 独立)
cd apps/daemon
go run ./cmd/uvp-daemon --stdio

### 开发模式 (Tauri + daemon)
1. 先 build daemon: cd apps/daemon && go build -o ../daemon/uvp-daemon ./cmd/uvp-daemon
2. cd apps/desktop && npm run tauri dev
   (lib.rs locate_daemon_binary 会从 CARGO_MANIFEST_DIR 找 ../../daemon/uvp-daemon)

### 生产打包 (TODO M4)
npm run tauri build
(需配 tauri.conf.json bundle.externalBin 把 uvp-daemon 打成 sidecar)

## 已知限制 (M2 范围内)

1. 前端摄像头/预览/平台命令面板是 M1 遗留,功能占位但后端未实现
   (list_cameras / subscribe_preview / platform_command 静默失败)
2. daemon 子进程崩溃时前端无 explicit 通知 (依赖 stdout EOF → 事件流断)
3. sidecar 打包配置留待 M4 (当前 dev 模式手工 build + 相对路径)
4. M2 只做注册,视频点播/目录/订阅/云台归 M3+
